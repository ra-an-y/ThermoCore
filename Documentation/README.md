# Purpose

Documentation exists to organize, explain, and provide navigation among ThermoCore repository artifacts.

It helps readers locate authoritative documents, supporting records, and repository guidance without redefining their content or authority.

---

# Scope

This directory may contain documents that define Framework specifications, govern repository practices, explain repository artifacts, record decisions or historical work, and provide navigation for repository concerns.

Research investigation, Framework implementation, material definitions, tests, Validation evidence, Performance Evaluation evidence, and example applications do not belong here merely because documentation may describe them. The authority of any document is determined by its declared status and applicable dependencies, not by its location in this directory.

---

# Relationship

Documentation connects readers to the repository areas that define, investigate, implement, support, verify, validate, and evaluate ThermoCore.

Framework Specifications within this directory govern Framework semantics according to their own declared authority. Repository Guidelines govern repository practices according to their own declared scope. This directory guide does not transfer authority between them.
