# Purpose

Documentation exists to organize, explain, and provide navigation among ThermoCore repository artifacts.

It helps readers locate authoritative documents, supporting records, and repository guidance without redefining their content or authority.

---

# Scope

This directory is responsible for documentation whose primary purpose is to explain repository artifacts, their terminology, their status, or their relationships.

Research investigation, Framework implementation, material definitions, tests, and example applications do not belong here merely because they may be described by documentation.

---

# Relationship

Documentation connects readers to the repository areas that define, investigate, implement, support, and examine ThermoCore.

Framework Specifications within this directory govern Framework semantics according to their own declared authority. Repository Guidelines govern repository practices according to their own declared scope. This directory guide does not transfer authority between them.
